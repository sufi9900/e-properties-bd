# E Properties BD — Supabase + Netlify দিয়ে সেটআপ গাইড

এই ভার্সনে ডাটা, ছবি আর admin লগইন — সবকিছু **Supabase** এ থাকে (ফ্রি প্ল্যানেই যথেষ্ট)। Netlify শুধু সাইটটাকে হোস্ট করে, কোনো Netlify Function বা Blobs আর লাগে না — তাই আগে যে "502 error" সমস্যাগুলো হতো, সেগুলোর আর সুযোগই নেই।

## কী কী বদলেছে

- **আগে:** Netlify Blobs + Netlify Functions (backend কোড নিজে লিখতে হতো)
- **এখন:** Supabase Postgres (listing ও settings ডাটা) + Supabase Storage (ছবি) + Supabase Auth (admin লগইন)
- Admin panel এ এখন **Website Settings** নামে একটা নতুন ট্যাব আছে — সেখান থেকে সাইটের নাম, ট্যাগলাইন, লোগো, হোমপেজের হেডলাইন, WhatsApp নাম্বার, ফুটারের লেখা/ঠিকানা/Facebook লিংক — সবকিছু বদলাতে পারবেন, কোনো কোড না ছুঁয়ে।
- সাইট আগের চেয়ে বেশি mobile-friendly করা হয়েছে (সার্চ বার, ক্যাটাগরি ট্যাব, ডিটেইলস পেজ — সব মোবাইলে ভালোভাবে কাজ করবে)।

---

## ধাপ ১ — Supabase প্রজেক্ট বানান

1. https://supabase.com এ গিয়ে ফ্রি সাইনআপ করুন।
2. **New Project** চাপুন। একটা নাম দিন (যেমন `eproperties-bd`), একটা ডাটাবেস পাসওয়ার্ড সেট করুন (এটা মনে রাখুন, পরে দরকার নাও হতে পারে তবে সংরক্ষণ করে রাখুন), region হিসেবে **Singapore (ap-southeast-1)** নিলে বাংলাদেশ থেকে দ্রুত হবে।
3. প্রজেক্ট তৈরি হতে ১-২ মিনিট লাগবে।

## ধাপ ২ — ডাটাবেস টেবিল ও নিরাপত্তা নিয়ম বসান

1. বাম পাশের মেনু থেকে **SQL Editor** এ যান।
2. **New query** চাপুন।
3. এই রিপোর মধ্যে থাকা `supabase/schema.sql` ফাইলের পুরো কনটেন্ট কপি করে পেস্ট করুন।
4. **Run** চাপুন। এটা করবে:
   - `properties` টেবিল বানাবে (সব listing এখানে থাকবে)
   - `site_settings` টেবিল বানাবে (হেডার/ফুটার/হোমপেজের লেখা এখানে থাকবে)
   - `property-images` নামে একটা পাবলিক Storage bucket বানাবে (ছবি এখানে থাকবে)
   - নিরাপত্তা নিয়ম (Row Level Security) সেট করবে: **যে কেউ শুধু পড়তে পারবে, কিন্তু শুধু লগইন করা admin-ই listing/settings/ছবি add-edit-delete করতে পারবে।**

## ধাপ ৩ — Admin ইউজার বানান (আপনার লগইন)

1. বাম পাশের মেনু থেকে **Authentication → Users** এ যান।
2. **Add user → Create new user** চাপুন।
3. আপনার একটা ইমেইল ও শক্তিশালী পাসওয়ার্ড দিন।
4. **"Auto Confirm User"** টিক দিয়ে রাখুন (তাহলে ইমেইল ভেরিফাই করা লাগবে না)।
5. Create করুন — এই ইমেইল/পাসওয়ার্ড দিয়েই আপনি `আপনার-সাইট.netlify.app/admin/` এ লগইন করবেন।

> শুধু আপনি নিজে যত admin ইউজার লাগবে তত বানাবেন (যেমন আপনার সহকর্মীর জন্য আলাদা লগইন)। সাইটে কোনো "Sign up" ফর্ম নেই, তাই বাইরের কেউ নিজে থেকে অ্যাকাউন্ট বানাতে পারবে না।

## ধাপ ৪ — API Key কপি করে কোডে বসান

1. বাম পাশের মেনু থেকে **Project Settings → API** এ যান।
2. **Project URL** কপি করুন।
3. **anon public** key কপি করুন (⚠️ **service_role** key না — ওটা গোপন, কখনো ব্যবহার করবেন না)।
4. আপনার কোডের `js/config.js` ফাইল খুলুন, এই দুইটা লাইন বদলান:

```js
const SUPABASE_URL = 'https://YOUR-PROJECT-REF.supabase.co';
const SUPABASE_ANON_KEY = 'YOUR-ANON-PUBLIC-KEY';
```

নিজের কপি করা ভ্যালু বসিয়ে সেভ করুন।

> **anon key ব্রাউজারে থাকা নিরাপদ** — এটা গোপন key না, এটা এমনভাবেই ডিজাইন করা যে সবাই দেখতে পারবে। আসল সুরক্ষা আসে ধাপ ২-এ সেট করা Row Level Security নিয়ম থেকে।

## ধাপ ৫ — GitHub এ আপলোড করে Netlify তে Deploy করুন

1. পুরো ফোল্ডারটা আপনার GitHub repo তে push করুন (অথবা GitHub ওয়েবসাইট থেকে ফাইলগুলো আপলোড/replace করুন)।
2. Netlify তে লগইন করুন → **Add new site → Import an existing project** → GitHub repo সিলেক্ট করুন।
3. Build settings এ কিছু বদলানো লাগবে না (এখন এটা প্লেইন static সাইট, কোনো build command লাগে না) — শুধু **Deploy** চাপুন।
4. কিছুক্ষণের মধ্যে `https://আপনার-সাইট.netlify.app` লিংকে সাইট লাইভ হয়ে যাবে।

> আগে যদি drag-and-drop দিয়ে deploy করা সাইট থাকে, তাহলে GitHub এর সাথে repo কানেক্ট করে নেওয়াই ভালো — এতে ভবিষ্যতে কোনো ফাইল বদলালে সাইট auto-update হবে।

## Admin প্যানেল কীভাবে ব্যবহার করবেন

`আপনার-সাইট.netlify.app/admin/` এ যান → ধাপ ৩ এ বানানো ইমেইল/পাসওয়ার্ড দিয়ে লগইন করুন।

### Listings ট্যাব
- **Add / Edit / Delete** — আগের মতোই কাজ করে।
- ছবি সরাসরি আপলোড করতে পারবেন (মোবাইল থেকেও), অথবা লিংক দিয়েও যোগ করতে পারবেন।
- Video tour এ শুধু YouTube/Facebook এর সাধারণ লিংক পেস্ট করলেই embed হয়ে যাবে।

### Website Settings ট্যাব (নতুন)
এখান থেকে কোনো কোড না ছুঁয়ে বদলাতে পারবেন:
- সাইটের নাম, ট্যাগলাইন, লোগো (header ও footer এ)
- হোমপেজের হিরো সেকশনের লেখা (eyebrow, headline, description)
- WhatsApp নাম্বার ও ডিফল্ট মেসেজ
- ফুটারের লেখা, অফিসের ঠিকানা, Facebook পেজ লিংক

**Save settings** চাপলেই সব visitor সাথে সাথে নতুন লেখা দেখতে পাবে।

## জরুরি টেকনিক্যাল নোট

- **ডাটা কোথায় থাকে?** Supabase এর নিজস্ব Postgres ডাটাবেসে, আর ছবি Supabase Storage এ। দুটোই Supabase এর ফ্রি প্ল্যানে (৫০০MB ডাটাবেস + ১GB storage) চলে যাবে সহজেই।
- **ছবির সাইজ:** প্রতিটা ছবি ৫MB এর নিচে রাখাই ভালো (মোবাইলে তোলা বড় সাইজের ছবি হলে আপলোডের আগে compress করে নিন)।
- **নতুন admin ইউজার লাগলে:** Supabase Dashboard → Authentication → Users → Add user থেকেই বানাতে পারবেন, কোনো কোড বদলানো লাগবে না।
- **পাসওয়ার্ড ভুলে গেলে:** Supabase Dashboard → Authentication → Users এ গিয়ে সেই ইউজারের পাশে থেকে পাসওয়ার্ড রিসেট করতে পারবেন।
- **কোড আপডেট করতে চাইলে:** GitHub repo তে ফাইল বদলে commit করলেই Netlify auto-deploy করবে।

## কোনো সমস্যা হলে

- Admin panel এ লগইন হচ্ছে না → `js/config.js` এ URL/anon key ঠিকমতো বসানো হয়েছে কিনা চেক করুন, আর Supabase এ ইউজার "Auto Confirm" করে বানানো হয়েছে কিনা দেখুন।
- Listing/settings save হচ্ছে না, "Unauthorized" দেখাচ্ছে → লগআউট করে আবার লগইন করুন (সেশন মেয়াদ শেষ হয়ে থাকতে পারে)।
- ছবি আপলোড হচ্ছে না → Supabase Dashboard → Storage এ গিয়ে `property-images` bucket টা আছে কিনা, আর সেটা Public কিনা চেক করুন (ধাপ ২ এর SQL ঠিকমতো চললে এটা এমনিতেই ঠিক থাকার কথা)।

কোনো জায়গায় আটকে গেলে বা এরর দেখলে, স্ক্রিনশটসহ জানালে ঠিক করে দিতে পারব।
